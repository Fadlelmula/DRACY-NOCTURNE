# Raw generated-art staging

Optional external image-generation outputs belong here. They are not used directly by the game.

The approved M01 pipeline uses the original transparent SVG sprites in `../expressions/`, `../poses/`, and `../outfits/`, generated by `game/tools/generate_art.py` and validated by `game/tools/build_dracy_assets.py`.

A paid image-generation attempt was unavailable due insufficient service credits. No failed or partial output is shipped, and no low-quality crop of the reference sheet is used as a sprite.
